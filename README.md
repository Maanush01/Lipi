# Lipi

A friendly AI assistant for Kannada, Hindi, and Kanglish, built with the Gemini API and Gradio.

## Features

- Replies in the user's language and script
- Streaming responses
- Retry with backoff and model fallback for API errors

## Run locally

1. `pip install -r requirements.txt`
2. Create a `.env` file with `GEMINI_API_KEY=your_key`
3. `python app.py`
